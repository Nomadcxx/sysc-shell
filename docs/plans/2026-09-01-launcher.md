# Milestone 7 Launcher Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship the v1 application launcher: a centered Noctalia-list panel (560×500) that searches installed desktop applications, ranks with fzf plus a ported usage store, and launches through Niri.

**Architecture:** A new `internal/launcher` service owns desktop-file scanning, scoring, usage history, prefix routing, and spawn, publishing immutable snapshots from collector and query goroutines. The shell gains one `PanelID` that projects the service state onto the landed M4 panel vocabulary (`KindTextField` + `KindVirtualList`) with no new node kinds. IPC and the documented Niri bind reuse the M4 panel toggle path.

**Tech Stack:** Go 1.26, pinned `github.com/go-freedesktop/desktopentry@v0.1.0` and `github.com/junegunn/fzf@v0.74.3`, existing M4 panel host, IPC server, and UI tree.

**Design:** `docs/plans/2026-09-01-launcher-design.md` (decisions D1–D16)
